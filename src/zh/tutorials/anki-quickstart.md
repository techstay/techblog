# 记词软件 anki 入门

最近在学习日语，需要背单词，一连看了好几个软件，发现要么是收费软件，要么广告太多。当然这也可以理解，但是对于用户来说就很难用了。所以最后我还是找到了开源免费的替代品 anki。anki 是一个卡片式的记词软件，软件是开源免费的，不包含任何内容。但是可以通过在社区安装牌组的方式添加生词本，然后就可以开始每天记忆了。anki 还可以通过注册账户的方式进行同步，这样即便在不同的客户端上也能同步学习记录。看了一圈下来，anki 确实是一个很好的选择，下面我就来介绍一下如何来使用 anki 吧。

## 下载和安装

首先到[anki 官网](https://apps.ankiweb.net/)，点击右上方的下载按钮即可开始下载 anki。anki 同时支持 Windows、Linux 和 macOS 平台，同时也支持 Android 和 iOS 平台，在跨平台支持方面可以说是非常优秀。

![download](https://p3-sign.toutiaoimg.com/tos-cn-i-6w9my0ksvp/4b7c43b84dec49a6a1bc52db12a15288~tplv-tt-origin-web:gif.jpeg?_iz=58558&from=article.pc_detail&lk3s=953192f4&x-expires=1756229474&x-signature=pzCa8ZUZXyjBvDrIOQyzn3XJGF8%3D)

## 开始使用

### 下载牌组

首次打开软件，你会发现软件是空的，这很正常，因为 anki 是开源软件，默认不带任何生词本。如果你要开始背词，第一件要做的事情就是去下载牌组，牌组就是 anki 里面的生词本。anki 有一个庞大的社区，所以你可以不费吹灰之力的找到大量牌组。

通过官网[分享的牌组](https://ankiweb.net/shared/decks)就可以查找牌组了，你可以通过语言或者用途来查找牌组，如果实在找不到，还可以通过搜索的方式来查找。

我这里只下载了几个牌组，因为下载太多的话也记不住。这里的牌组资源真的很多，建议只下载自己需要的几个。

- [4000 Essential English Words (all books)](https://ankiweb.net/shared/info/1104981491)，这个牌组的评分挺高，英英释义，包含了近 4000 单词，附带读音和图片说明，是很好的学习材料
- [简体・繁體中文】【egg rolls】JLPT N1 ～ N5 单词＋补充（含语音、例句）v2](https://ankiweb.net/shared/info/832276382)，这个牌组包含了 14000 多条笔记，涵盖了 N1-N5 的大量单词，并包含了语音和例句，因为牌组实在是太大，作者建议直接去 github 上下载，足见其良心程度
- [Japanese course based on Tae Kim's grammar guide & anime](https://ankiweb.net/shared/info/911122782)，这个牌组包含了 2000 多条例句和语音，涵盖大量知识点，特点是所有例句全部来自日本动画，喜欢通过动漫学日语的可以看看

这里只列举我下载的几个，anki 上还有大量牌组就不多做介绍了，有兴趣的可以自行去查看。下载完成之后，点击 anki 菜单栏的「文件->导入」，选择刚刚下载的`.apkg`格式的牌组，就可以导入到 anki 中了。一些牌组有自己的说明，导入之前需要仔细查看，并按照说明进行设置。

### 开始记词

一切准备就绪之后，就可以开始记词了。点开之前导入的牌组，点击要学习的章节就可以开始学习了。软件会开始一个一个显示单词，我们可以开始回忆单词的意思，然后点击显示答案，就会列出单词的释义。根据对单词的掌握程度，选择相应的选项。对于不会或者比较困难的单词，anki 会反复提醒你。对于你认为容易的单词，anki 就会隔一段时间再提醒你复习。这样经过长期的学习之后，你的词汇量就会逐渐提升。所以背单词是一个长期的过程，切勿三天打鱼两天晒网，这个过程得慢慢坚持下去才会看到效果。

如果你使用电脑版的 anki 的话，还可以使用快捷键来节约点击按钮的时间。在电脑版上，显示答案是空格键，而选择四个选项则分别是数字键 1-4。如果你下载的牌组包含音频的话，还可以点击字母 R 键播放音频辅助记忆。

## 高级设置

### 插件

anki 也有自己的插件系统，可以补充软件没有的功能。点击官网右上角的[addons](https://ankiweb.net/shared/addons)即可打开插件列表，在这里可以浏览插件，点击插件名称进入详情页面就可以查看插件的详细说明。同时插件详情页面里还会提供插件 ID，这是一串数字代码。在 anki 软件中，点击菜单栏「工具」-> 「插件」，打开插件对话框，然后点击右边的「获取插件」按钮，粘贴刚才的插件 ID，就可以安装插件了。插件安装完成之后需要重启软件才能生效。

目前我觉得 anki 的功能挺完整的，没什么必须安装的插件，所以我只安装了一个[Review Heatmap](https://ankiweb.net/shared/info/1771074083)，它模仿 GitHub 的提交视图，为 anki 添加了记忆单词的热点图，可以显示记忆单词的日程记录。这个插件的 ID 是`1771074083`，通过上面介绍的方式在 anki 中就可以安装。安装完成重新打开软件就可以看到热点图了。

![热点图](https://raw.githubusercontent.com/glutanimate/review-heatmap/main/screenshots/review-heatmap-1.png)

### 多端同步

首先点击官网右上角的[AnkiWeb](https://ankiweb.net)，注册一个账户。注册完成之后，打开软件，点击菜单栏「工具」->「设置」，找到「同步」，输入刚刚注册的账户。这样就开启了 anki 的多端同步功能，以后在其他设备的 anki 软件上登录同一个账户，就可以自动同步牌组以及学习记录了。需要注意的是，anki 作为一个开源软件，它的资金比较紧张，会删除不活跃账户的牌组数据。如果你可能长时间不使用 anki，建议自己手动备份一下牌组数据和学习记录。

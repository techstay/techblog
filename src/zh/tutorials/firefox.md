# 火狐浏览器使用教程

之前我用过不少浏览器，不过兜兜转转最后还是回到了火狐的怀抱。最后选用火狐的原因很简单，就是「新标签页打开收藏夹」、「新标签页显示搜索结果」这几个功能，但是没想到这么简单的功能不管是 Chrome 还是 Edge 浏览器竟然都没做，所以最后可选的基本上只有火狐浏览器了。所以最后就有了这篇文章，把我使用火狐浏览器的一些经验记录下来。

## 功能定制

### 开启垂直标签页

首先在火狐浏览器的工具栏空白处右键，打开定制工具栏功能，这项功能允许你按照自己的喜好对火狐浏览器的界面进行极大程度的定制。这里就按照个人喜好，随意更改火狐浏览器的布局。

我还建议在标签页栏上右键点击，然后选择「开启垂直标签页」，现在主流显示器的显示宽度是足够的，但是网页并没有做好宽屏优化，这导致很多网页两边存在空白边。既然这样，不如干脆开启垂直标签页，把多余的宽度利用起来，这样高度上还能解放一部分空间。而且现在不少人喜欢浏览器同时开大量网页，开启垂直标签页也可以更方便的寻找自己想要的标签页。

### 新标签页打开收藏网页和搜索结果

这项功能我认为非常重要，但是主流浏览器竟然都没有做这项功能，只有火狐浏览器和一些 Chrome 衍生版实现了这个功能。这几项功能我认为非常方便，不需要每次打开网页先新建一个空页面，然后在空页面上打开网页或者开始搜索。

要开启这几项功能非常简单，打开火狐浏览器的<about:config>页面，然后搜索以下几项，全部开启即可。

- browser.search.openintab
- browser.tabs.loadBookmarksInTabs
- browser.urlbar.openintab

## 浏览器美化

### Firefox-WinUI 主题

火狐浏览器的默认外观很一般，但是我们可以通过扩展以及用户主题来自定义软件的外观。这里我利用[Firefox-WinUI](https://github.com/Lockframe/Firefox-WinUI)这个用户主题，可以让火狐浏览器的外观和 Windows 11 紧密集成，并支持亚力克半透明效果，效果相当不错。

### 复制配置文件

首先在火狐浏览器中打开<about:support>页面，然后找到`Profile Folder`或者叫「配置文件文件夹」，点击旁边的「打开文件夹」按钮，打开配置文件文件夹。

然后下载`Firefox-WinUI`项目中的主题压缩包，解压，将`chrome`文件夹和`user.js`文件复制到配置文件文件夹中。

### 主题设置

最后在<about:config>页面中新建或修改以下条目，在 Firefox-WinUI 项目中还有更多可更改项，有需求的参考项目主页。

开启浏览器半透明效果：

- widget.windows.mica
- widget.windows.mica.popups (设置为 1 或者 2)
- browser.tabs.allow_transparent_browser
- uc.winui.more-acrylic（在导航栏、书签栏和选中的标签页上添加亚力克效果）
- uc.winui.acrylic-animations（实验型的亚力克动画效果）

全部设置完成之后，现在你的火狐浏览器应该已经大变身了，并且开启了精美的半透明效果，相信你也会爱上使用火狐浏览器的。

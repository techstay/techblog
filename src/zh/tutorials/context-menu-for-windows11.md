# 🛠️ ContextMenuForWindows11

Windows 11 被人诟病的一点就是它的右键菜单，把原本的菜单功能拆分开来放到了二级菜单，导致操作更加繁琐。所以很多人都选择将右键菜单改回传统样式。不过也有人喜欢 Windows 11 的右键菜单，那么能不能直接在 Windows 11 右键菜单里添加项目呢？当然可以，这就是今天我要向大家介绍的[ContextMenuForWindows11](https://github.com/ikas-mc/ContextMenuForWindows11)，这个软件可以自定义 Windows 11 的右键菜单，将右键菜单设置为你想要的样子。

## 📥 安装

首先需要下载软件，最简单的办法是直接在微软商店下载安装，但是微软商店的版本是付费版。如果不想付费的话，可以安装[Github 版](https://github.com/ikas-mc/ContextMenuForWindows11/releases)。在安装之前，需要安装证书：打开证书文件，导入 ➡️ 本地计算机 ➡️ 将所有证书放入下列存储 ➡️ 信任的人，然后点击完成。

然后安装 appx 软件包即可，如果提示缺少依赖，那么就安装依赖项。

## 🖱️ 使用

软件的使用方法很简单，点击左边的加号，然后输入菜单项的标题，启动路径，参数，图标等等，最后点击下面的保存。这样就成功的添加好了新的 Windows 11 菜单项，这样以后就可以在右键菜单中使用了！
